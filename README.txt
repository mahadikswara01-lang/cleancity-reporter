CleanCity Reporter - how to run (Windows)
-----------------------------------------
1. Install Python 3 (tick "Add Python to PATH").
2. Open Command Prompt inside this folder and run:
      pip install -r requirements.txt
3. (Optional) add demo data:   python seed.py
4. Start the website:          python app.py
5. Open in browser:            http://127.0.0.1:5000

Citizen: register a new account, or use demo@example.com / demo123 (after seed.py)
Admin:   http://127.0.0.1:5000/admin/login   ->  admin / admin123
